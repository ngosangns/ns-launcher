# Vũ khí

Một file cho mỗi loại vũ khí, dạng bảng, chứa **toàn bộ** vũ khí đã phát
hành thuộc loại đó (mọi độ hiếm 1★–5★). Mỗi vũ khí gồm:

- Độ hiếm, ATK cơ bản (cấp 1 và cấp 90), loại chỉ số phụ và giá trị chỉ số
  phụ ở cấp 90.
- Hiệu ứng đặc biệt (passive): mô tả đầy đủ, số liệu ở **tinh luyện 1 (R1)**
  và **tinh luyện 5 (R5)** để thấy rõ mức tăng.
- Cách lấy (banner giới hạn / chế tạo / battle pass / sự kiện / phần thưởng
  cốt truyện...).
- Nhân vật phù hợp nhất (1–3 nhân vật đại diện, không cần liệt kê hết).

## File theo loại

- `kiem.md` — Sword (kiếm một tay).
- `dai-kiem.md` — Claymore (đại kiếm).
- `thuong.md` — Polearm (thương).
- `cung.md` — Bow (cung).
- `phap-khi.md` — Catalyst (pháp khí).
